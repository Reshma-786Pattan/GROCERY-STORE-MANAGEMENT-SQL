# Grocery Store Management

## Project Overview

This project is a **Grocery Store Management System** developed using **MySQL**. It demonstrates **relational database design and business analysis using SQL queries** to generate insights into customers, products, sales, suppliers, employees, and orders.

## Features

* 7 relational tables
* Primary Keys and Foreign Keys
* AUTO_INCREMENT
* CASCADE operations
* CSV data import
* Customer and product analysis
* Sales and order trend analysis
* Supplier contribution analysis
* Employee performance analysis
* Business analysis using SQL queries

## SQL Concepts Used

* DDL
* Joins
* GROUP BY
* Aggregate Functions
* Date Functions
* Subqueries
* CTEs
* Window Functions
* RANK()
* DENSE_RANK()
* ORDER BY
* LIMIT

## Key Business Questions

* Which customers have placed the most orders?
* Which products generate the highest revenue?
* Which category generates the highest sales revenue?
* Which suppliers contribute the most to sales?
* What are the monthly sales trends?
* Which employees process the most orders?
* Which employees generate the highest sales revenue?
* What is the highest-value order?
* Which product is the second highest-selling product?
